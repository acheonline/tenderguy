---

Выполни в рабочем дереве и покажи полный вывод каждого шага (не пересказ):

1. `gofmt -l .`
2. `go build ./...`
3. `go vet ./...`
4. `"$(go env GOPATH)/bin/golangci-lint" run ./...`
5. `go test -race -coverprofile=coverage.out ./...`
6. `go tool cover -func=coverage.out | tail -20`

Затем таблица: гейт → статус → что падает. Если шаг 5 или 6 выявил падение либо покрытие
критичного модуля ниже 70 % — явно скажи «PR не готов» и назови пакет. Ничего не починивай
на этом шаге; починка — только по запросу.
